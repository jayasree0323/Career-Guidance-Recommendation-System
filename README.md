# Career Guidance and Recommendation System
A machine learning based career guidance and recommendation system using Python and Power BI.

## 📌 About the Project
This project uses machine learning to recommend suitable career options based on a student's education level, specialization, skills, and interests.
The project also includes a Power BI dashboard to visualize career-related patterns and insights from the dataset.

## 🎯 Objectives
- Analyze student career-related data
- Clean and preprocess the dataset
- Perform exploratory data analysis
- Apply machine learning algorithms
- Compare different classification models
- Recommend suitable career options
- Visualize career insights using Power BI

## 📊 Dataset
The project uses the Perfectly Realistic Career Guidance Dataset.
After removing duplicates records, the dataset contains:
- 1,207 unique student records
- 6 columns
- 55 career options
- 37 specializations

### Dataset Features
- Education Level
- Specialization
- Skills
- Interests
- Recommended Career
- Career Description

## 🤖 Machine Learning
The following algorithms were implemented and compared:
| Model | Accuracy |
|---|---:|
| Logistic Regression | 28.93% |
| Decision Tree | 19.83% |
| Random Forest | 19.42% |
Logistic Regression achieved the highest accuracy among the tested models and was selected as the final model.
